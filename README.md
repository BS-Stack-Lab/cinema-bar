# Cinema Bar

개인 영화 예매 오픈 감시용 로컬 메뉴바 앱입니다. 저장한 CGV·Megabox·롯데시네마의 극장, 정확한 작품 제목, 한국 상영일, 포맷만 확인합니다. 각 사용자의 앱 데이터와 Discord 웹훅은 독립적이며 중앙 서버나 공용 계정이 필요하지 않습니다.

Node.js 22.12 이상과 npm을 사용합니다. 이 저장소의 잠금 파일로 `npm ci`를 실행하고, `npm run build`로 현재 호스트용 Electron 앱을 만드세요. macOS에서는 `release/Cinema Bar-darwin-arm64/Cinema Bar.app`(Intel은 x64)을 열면 됩니다. 로컬 미서명 앱이며 배포용 서명·공증은 포함하지 않습니다. 개발 실행은 `npm run dev`입니다. 개발 Electron은 OS 로그인 항목에 등록되지 않습니다.

트레이 아이콘을 누르면 440px 창이 열리고 다시 누르면 숨겨집니다. 창 닫기는 감시를 유지합니다. 하단 전원 버튼이나 트레이 메뉴의 **앱 종료**가 프로세스와 감시를 끝냅니다. 다중 실행은 하나의 인스턴스로 합칩니다.

1. Discord 서버에서 원하는 채널의 설정 → 연동 → 웹후크 → 새 웹후크를 사용해 직접 주소를 만드세요. 웹훅 생성 권한은 서버 관리자에게 확인하세요.
2. 앱 **설정**의 비밀번호 필드에 주소를 붙여 넣고 **안전하게 연결**을 누르세요. OS safeStorage로 암호화하며 주소 원문을 화면·로그·renderer snapshot에 다시 내보내지 않습니다. OS 암호화를 사용할 수 없으면 저장과 전송이 중지됩니다.
3. **감시 목록**에서 극장 ID와 이름, 정확한 작품 제목, 상영일과 포맷을 저장하세요. 공식 예매 페이지의 CGV `siteNo`, Megabox `brchNo`, 롯데시네마 `CinemaID`를 사용합니다. ID는 영화관 공식 페이지에서 확인해야 합니다. 애니메이션 분류를 추측하지 않으므로 원하는 애니메이션의 제목을 직접 입력하세요.
4. 첫 성공 조회는 기존 상영의 기준선만 만듭니다. 다음 조회부터 새 예매 가능 상영이나 예매 불가→가능 전환을 알려줍니다. 규칙 수정 후에도 새 기준선부터 시작합니다. 같은 상영을 여러 규칙이 찾아도 한 번만 대기열에 넣습니다.

조회 간격은 기본 120초, 60~3600초입니다. 조회 실패를 매진이나 상영 없음으로 표시하지 않습니다. CGV의 공개 API는 HTTP 403이나 접근 제한을 반환할 수 있습니다. 실제 공개 경로와 응답 parser를 사용하며 차단을 우회하거나 인증 서명을 만들지 않습니다. Megabox·롯데시네마도 공개 API 변경·지역·네트워크에 따라 실패할 수 있습니다. 확인할 수 없는 포맷은 특정 포맷 규칙과 일치하지 않습니다. 모든 포맷 규칙은 포맷 미제공 상영도 포함할 수 있습니다. 잔여 좌석이 없거나 공식 예매 가능 플래그가 꺼지면 알리지 않습니다.

새 알림은 전송 전에 디스크에 저장됩니다. Discord의 429 대기 시간을 지키고 일시 오류는 지수 backoff로 최대 8회 재시도합니다. 401/403/404는 연결 오류로 표시하고 웹훅 교체를 기다립니다. 전송 대기는 100개·24시간, 로컬 이력은 100개입니다. 보존 만료·한도 초과를 이력으로 남깁니다. Discord는 외부 idempotency key를 지원하지 않으므로 **응답 직전 중단이나 불명확한 timeout에는 같은 알림이 다시 도착할 수 있습니다(at-least-once)**. 정확히 한 번 전달을 보장하지 않습니다. 전체 일시 정지는 조회와 전송을 함께 멈춥니다. 연결을 교체·삭제하거나 규칙을 수정·삭제하면 이전 작업과 대기 항목을 무효화합니다.

패키지 앱의 첫 실행은 로그인 후 자동 시작을 켭니다. 설정에서 끄면 선택을 유지합니다. 절전에는 요청을 취소하고 복귀·네트워크 복구 때 하나의 감시 흐름으로 다시 연결합니다. 로그인 전 부팅 직후 실행을 보장하지 않습니다. 데이터는 OS 사용자별 Electron `userData` 아래 `state.json`과 마지막 유효 백업에 저장됩니다. 두 파일 모두 손상되거나 미래 버전이면 원본을 보존하고 감시를 중지합니다. 설정 복구 안내에서 명시적으로 초기화할 수 있습니다.

`npm run format:check`, `npm run lint`, `npm run test`, `npm run build`, `npm run test:desktop`으로 검증합니다. 단위·통합·UI 테스트는 가짜 공급자, 시계, 암호화/전송 adapter를 사용합니다. `test:desktop`은 실제 생성된 Electron 패키지를 임시 프로필로 실행하고 mock 공급자·Discord·로그인 설정만 사용하여 UI, tray, lifecycle, IPC, 단일 인스턴스를 확인합니다. Electron `capturePage` PNG와 JSON 증거는 `CINEMA_SMOKE_OUTPUT`에 저장합니다. 실제 Discord 전송이나 OS 로그인 항목 쓰기, 기기 절전·재부팅·로그아웃을 수행하지 않습니다. macOS 호스트 패키지만 검증했으며 실제 로그인 후 자동 시작·기기 절전 복귀와 다른 OS는 사용 환경별 수동 확인이 필요합니다.

`npm run probe:providers`는 세 구현 adapter의 공개 읽기 전용 경로를 낮은 빈도로 조회합니다. 오류는 그대로 기록하며 parser fixture를 실제 조회 성공으로 표시하지 않습니다. 롯데 catalog에서 정확한 제목을 찾지 못한 빈 결과는 시간표가 검증되었다는 뜻이 아닙니다. 개인 Discord 주소를 저장소, `.env`, Vite 환경 변수나 공유 스크린샷에 넣지 마세요.
