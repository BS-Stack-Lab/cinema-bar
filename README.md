## 어떤 서비스인가요?

**Cinema Bar는 각자의 컴퓨터에 설치해서 사용하는 영화 예매 오픈 알림 앱입니다.**

애니메이션 개봉을 기다리거나, 자주 가는 극장과 특별관의 예매가 열렸는지 확인할 때 사용할 수 있습니다. 영화관·지역·극장·작품·상영일을 저장해 두면 앱이 주기적으로 예매 가능한 회차를 확인합니다. 이미 예매가 열린 작품도 저장 후 첫 성공 조회부터 알림을 받을 수 있습니다.

작은 픽셀 영사기와 함께 메뉴바에서 감시 상태를 확인하고, 공식 포스터가 들어간 카드로 저장한 작품을 살펴보세요.

**각 사용자가 앱을 설치하고 자신의 디스코드 웹훅을 연결합니다.** 감시는 각자의 컴퓨터와 네트워크로 실행하며, 별도 유료 서버를 준비할 필요가 없습니다.

<br>

## 주요 기능

| 기능                     | 설명                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------- |
| 🎬 세 영화관 지원        | CGV·메가박스·롯데시네마의 공개 예매 정보를 확인합니다.                                      |
| 🔎 극장 선택과 작품 검색 | 영화관과 지역을 고른 뒤 극장을 선택하고, 애니메이션을 포함한 작품을 제목으로 검색합니다.    |
| 🗓️ 날짜·포맷별 감시      | 한국 시간 기준 상영일과 모든 포맷·2D·3D·IMAX·4DX·DOLBY·SCREENX 조건을 저장합니다.           |
| ⏱️ 가장 빠른 회차 알림   | 선택한 날짜와 포맷에서 가장 빠른 예매 가능 미래 회차 한 건을 알려줍니다.                    |
| 🔔 앱 알림과 디스코드    | 앱 팝업을 먼저 처리하고, 연결한 개인 디스코드 채널에도 알림을 보냅니다.                     |
| 🖼️ 공식 영화 포스터      | 공식 목록에서 확인한 포스터를 원본 비율로 표시하고, 이미지가 없으면 티켓 배너를 보여줍니다. |
| 🌙 자동 복귀             | 절전 해제·네트워크 복구 후 감시를 이어가며, 로그인 후 자동 시작을 설정할 수 있습니다.       |
| 💾 내 기기에 저장        | 감시 조건·설정·알림 기록은 로컬에 저장하고 웹훅은 OS 암호화 저장소로 보호합니다.            |

포맷은 해당 영화관이 제공한 회차 정보에서 식별합니다. 목록에 있는 모든 극장이 모든 특별관 포맷을 운영하는 것은 아닙니다.

## 설치와 실행

### macOS 앱으로 사용하기

1. 전달받은 macOS 앱 ZIP을 압축 해제합니다.
2. **Cinema Bar.app**을 **응용 프로그램** 폴더로 옮깁니다.
3. 앱을 실행하고 상단 메뉴바의 **영사기 / CB** 아이콘을 누릅니다.
4. **감시 목록 → ＋ 추가**에서 첫 감시를 저장합니다.

현재 패키지는 서명·공증 전의 로컬 빌드입니다. 배포 파일은 본인이 빌드했거나 출처를 확인한 파일을 사용하세요. 실기기 검증은 macOS Apple Silicon에서 진행했습니다. Windows·Linux는 추가 실기기 검증이 필요합니다.

### 소스에서 직접 실행하기

Node.js **22.12 이상**과 npm을 준비한 뒤 저장소 루트에서 실행합니다.

```sh
npm ci
npm run dev
```

설치형 앱을 직접 빌드하려면 다음 명령을 사용합니다.

```sh
npm run build
```

현재 실행 중인 OS와 CPU에 맞는 패키지가 `release/`에 생성됩니다. macOS Apple Silicon의 결과는 다음 위치입니다.

```text
release/Cinema Bar-darwin-arm64/Cinema Bar.app
```

Intel Mac에서는 경로의 아키텍처가 `x64`입니다. 로그인 후 자동 시작은 패키지로 설치한 앱에서 설정합니다.

## 첫 감시 등록하기

1. **감시 목록 → ＋ 추가**를 누릅니다.
2. **영화관 → 지역 → 극장**을 차례로 선택합니다. 극장 ID를 직접 찾을 필요가 없습니다.
3. **작품 검색**에 제목 일부를 입력하고 **검색 결과에서 작품을 선택**합니다.
4. **상영일**과 **상영 포맷**을 고릅니다.
5. 원하면 **가장 빠른 회차만 알림** 버튼을 켭니다.
6. **저장 후 감시 켜기**를 확인하고 **감시 저장**을 누릅니다.

작품은 영화관의 공식 예매 목록에서 검색합니다. 아직 목록에 없는 작품은 나중에 **목록 새로고침**으로 다시 확인하세요. 각 감시는 **지정한 날짜**를 대상으로 하며, 매주 같은 요일을 반복하는 예약은 현재 제공하지 않습니다.

### 알림은 언제, 몇 번 오나요?

| 저장한 조건                              | 알림 동작                                                                                                              |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **모든 포맷**                            | 같은 작품·극장·날짜의 예매가 열리면 앱과 디스코드에 각각 한 번 알립니다. 가장 빠른 시간과 실제 포맷을 함께 표시합니다. |
| **특정 포맷 + 가장 빠른 회차만 알림 켬** | 선택한 포맷에 맞는 가장 빠른 미래 회차 한 건을 날짜별 한 번 알립니다.                                                  |
| **특정 포맷 + 가장 빠른 회차만 알림 끔** | 조건에 맞는 예매 가능 회차를 회차별로 알립니다.                                                                        |

- 이미 예매가 열려 있어도 **저장 후 첫 성공 조회**에서 알립니다.
- **모든 포맷**은 여러 포맷과 시간대가 한꺼번에 열려도 알림 한 건으로 안내합니다.
- 날짜별 단일 알림을 이미 받았다면 이후 회차 추가나 더 빠른 회차 발견으로 반복 알리지 않습니다. 선택 버튼을 껐다 다시 켜도 같은 날짜의 완료 기록을 유지합니다.
- 날짜·작품·극장 등 감시 범위를 바꾸면 새로운 조건으로 확인합니다.
- 앱과 디스코드는 목적지별로 기록합니다. 앱 알림만 먼저 사용하다 디스코드를 연결하면, 다음 성공 조회에서 디스코드에 아직 알리지 않은 조건을 안내할 수 있습니다.

알림의 표시 형식은 다음과 같습니다.

```text
🎬 저장한 작품
CGV · 선택한 극장
2026-10-24 18:10 · 2D · 3관
가장 빠른 예매 가능 회차를 찾았어요
```

## 디스코드 연결하기

**자신의 서버와 채널에서 웹훅을 직접 만든 뒤 앱에 연결합니다.** 별도 봇 계정을 발급하거나 다른 사용자의 연결 정보를 공유할 필요가 없습니다.

1. 알림을 받을 디스코드 서버의 텍스트 채널을 선택합니다.
2. **채널 설정 → 연동 → 웹후크**에서 새 웹훅을 만듭니다. 웹훅 관리 권한이 필요합니다.
3. 알림을 받을 채널과 표시 이름을 확인하고 **웹후크 URL 복사**를 누릅니다.
4. Cinema Bar의 **설정 → Discord 연결 → 개인 웹훅 주소**에 붙여 넣습니다.
5. **안전하게 연결**을 누릅니다. 기존 연결을 바꿀 때는 **연결 교체**를 사용합니다.

연결 없이도 앱 팝업은 사용할 수 있습니다. 웹훅 주소는 저장 후 화면에 다시 표시하지 않으며, 디스코드 연결을 제거하려면 **연결 삭제**를 누릅니다.

웹훅 주소는 메시지를 보낼 수 있는 비밀 주소입니다. 저장소·공개 스크린샷·공유 문서에 넣지 마세요.

## 메뉴바와 알림 사용하기

| 화면          | 할 수 있는 일                                                                      |
| ------------- | ---------------------------------------------------------------------------------- |
| **대시보드**  | 활성 감시 수, 전송 대기, 최근 조회 상태를 확인합니다.                              |
| **감시 목록** | 포스터와 가장 빠른 회차를 보고, 감시를 추가·수정하거나 개별로 켜고 끕니다.         |
| **알림 기록** | 최근 100개의 앱 알림 표시 요청과 디스코드 전송 결과를 확인합니다.                  |
| **설정**      | 앱 알림, 개인 웹훅, 조회 간격, 로그인 후 자동 시작, 자동 잠자기 방지를 설정합니다. |

- 상단 **Cinema Bar 헤더를 드래그**하면 창을 이동할 수 있습니다.
- 창을 닫거나 숨겨도 감시는 이어집니다. **앱 종료**를 누르면 감시도 종료됩니다.
- 앱 팝업은 화면 우측 상단에 표시되고 약 8초 뒤 닫힙니다. macOS 알림센터에는 남지 않습니다.
- 메뉴바 아이콘이 보이지 않을 때는 **Dock에서 Cinema Bar를 열어** 상태를 확인할 수 있습니다.

조회 간격은 새 설치 기준 **120초**, 설정 가능한 범위는 **60~3600초**입니다. 네트워크나 영화관 측의 요청 제한이 있으면 다음 조회가 늦어질 수 있습니다.

## 화면이 꺼지거나 재부팅하면 어떻게 되나요?

**설정 → 감시 중 자동 잠자기 방지**를 켜면 활성 감시가 작동하는 동안 자동 시스템 잠자기를 막아, 화면이 꺼져도 감시를 이어갈 수 있습니다. 이 설정은 기본적으로 꺼져 있으며 배터리 사용량이 늘어날 수 있습니다.

| 기기 상태                              | 동작                                                                     |
| -------------------------------------- | ------------------------------------------------------------------------ |
| 화면만 꺼짐 + 자동 잠자기 방지 작동 중 | 감시를 계속합니다.                                                       |
| 수동 잠자기·노트북 덮개 닫힘           | 잠자기 동안 감시가 멈추고, 깨어나면 다시 조회합니다.                     |
| 네트워크 연결 끊김                     | 감시가 대기하다 연결 복구 후 다시 확인합니다.                            |
| 전원 꺼짐                              | 감시가 멈춥니다. 로그인 후 자동 시작을 켰다면 다음 로그인 뒤 재개합니다. |
| 전체 일시 정지·앱 종료                 | 사용자가 다시 실행할 때까지 감시를 멈춥니다.                             |

패키지 첫 실행은 **로그인 후 자동 시작**을 켭니다. 설정에서 끄면 그 선택을 유지합니다. 로그인 전 부팅 단계에서 실행하는 시스템 서비스는 아닙니다.

## 자주 묻는 질문

### 비용이 드나요?

감시와 알림 전송은 설치한 컴퓨터에서 실행하므로 중앙 감시 서버 운영비가 필요하지 않습니다. CPU·메모리·네트워크·전력은 각 사용자의 기기에서 사용합니다.

### 예매나 결제도 해주나요?

Cinema Bar는 예매 가능한 회차를 확인해 알림을 보냅니다. 실제 좌석 선택·예매·결제는 공식 영화관에서 진행합니다.

### 알림이 늦거나 같은 알림이 다시 올 수도 있나요?

주기 조회 방식이므로 오픈 순간과 알림 사이에 차이가 생길 수 있습니다. 영화관 응답 지연이나 요청 제한은 오류로 표시합니다. 조건에 맞는 회차가 없다는 뜻으로 바꿔 처리하지 않습니다.

앱은 목적지별 중복 기록을 사용합니다. 다만 디스코드 전송 응답이 불명확한 상태에서 재시도하면 같은 메시지가 다시 도착할 수 있습니다. 앱도 표시 기록 저장과 실제 팝업 표시 사이에 종료되면 팝업을 놓칠 수 있습니다.

### 내 설정과 웹훅은 어디에 저장되나요?

감시 조건·설정·알림 기록은 OS 사용자별 앱 데이터에 저장합니다. macOS 설치 앱의 경로는 다음과 같습니다.

```text
~/Library/Application Support/Cinema Bar/
```

웹훅은 Electron `safeStorage`로 암호화합니다. OS 암호화 저장소에 연결할 수 없으면 디스코드 연결 저장·전송이 제한되며, 앱 팝업은 별도로 사용할 수 있습니다.
