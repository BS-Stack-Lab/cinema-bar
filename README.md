## 어떤 서비스인가요?

**Cinema Bar는 각자의 컴퓨터에 설치해서 사용하는 영화 예매 오픈 알림 앱입니다.**

애니메이션 개봉을 기다리거나, 자주 가는 극장과 특별관의 예매가 열렸는지 확인할 때 사용할 수 있습니다. 영화관·지역·극장·작품·상영일을 저장해 두면 앱이 주기적으로 예매 가능한 회차를 확인합니다. 이미 예매가 열린 작품도 저장 후 첫 성공 조회부터 알림을 받을 수 있습니다.

작은 픽셀 영사기와 함께 메뉴바에서 감시 상태를 확인하고, 공식 포스터가 들어간 카드로 저장한 작품을 살펴보세요.

**각 사용자가 앱을 설치하고 자신의 디스코드 웹훅을 연결합니다.** 감시는 각자의 컴퓨터와 네트워크로 실행하며, 별도 유료 서버를 준비할 필요가 없습니다.

<br>

## 주요 기능

| 기능                     | 설명                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------- |
| 🎬 세 영화관 지원        | CGV·메가박스·롯데시네마의 공개 예매 정보를 확인합니다.                                      |
| 🔎 극장 선택과 작품 검색 | 영화관과 지역을 고른 뒤 극장을 선택하고, 애니메이션을 포함한 작품을 제목으로 검색합니다.    |
| 🗓️ 날짜·포맷별 감시      | 한국 시간 기준 상영일과 모든 포맷·2D·3D·IMAX·4DX·DOLBY·SCREENX 조건을 저장합니다.           |
| ⏱️ 가장 빠른 회차 알림   | 선택한 날짜와 포맷에서 가장 빠른 예매 가능 미래 회차 한 건을 알려줍니다.                    |
| 🔔 앱 알림과 디스코드    | 앱 팝업을 먼저 처리하고, 연결한 개인 디스코드 채널에도 알림을 보냅니다.                     |
| 🖼️ 공식 영화 포스터      | 공식 목록에서 확인한 포스터를 원본 비율로 표시하고, 이미지가 없으면 티켓 배너를 보여줍니다. |
| 🌙 자동 복귀             | 절전 해제·네트워크 복구 후 감시를 이어가며, 로그인 후 자동 시작을 설정할 수 있습니다.       |
| 💾 내 기기에 저장        | 감시 조건·설정·알림 기록은 로컬에 저장하고 웹훅은 OS 암호화 저장소로 보호합니다.            |

포맷은 해당 영화관이 제공한 회차 정보에서 식별합니다. 목록에 있는 모든 극장이 모든 특별관 포맷을 운영하는 것은 아닙니다.

## 설치와 실행

사용 중인 운영체제의 설치 파일을 선택하세요. Node.js나 개발 도구 설치 없이 앱으로 사용할 수 있습니다.

- **Windows**: [설치 파일(.exe) 다운로드](https://github.com/BS-Stack-Lab/cinema-bar/releases/download/v0.2.0/Cinema-Bar-0.2.0-Windows-x64-Setup.exe) → [Windows 설치 방법](#windows-앱으로-사용하기)
- **macOS**: [설치 파일(.dmg) 다운로드](https://github.com/BS-Stack-Lab/cinema-bar/releases/download/v0.2.0/Cinema-Bar-0.2.0-macOS-arm64.dmg) → [macOS 설치 방법](#macos-앱으로-사용하기)

### macOS 앱으로 사용하기

| 다운로드                                                                                                                       | 대상과 용도                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------- |
| **[macOS DMG 다운로드](https://github.com/BS-Stack-Lab/cinema-bar/releases/download/v0.2.0/Cinema-Bar-0.2.0-macOS-arm64.dmg)** | Apple Silicon · macOS 13 이상 · 권장. 앱을 응용 프로그램으로 드래그해서 설치합니다. |
| [macOS ZIP 다운로드](https://github.com/BS-Stack-Lab/cinema-bar/releases/download/v0.2.0/Cinema-Bar-0.2.0-macOS-arm64.zip)     | Apple Silicon · macOS 13 이상 · 압축을 풀고 앱을 직접 복사합니다.                   |
| [SHA256 체크섬](https://github.com/BS-Stack-Lab/cinema-bar/releases/download/v0.2.0/SHA256SUMS.txt)                            | 릴리스 설치 파일 · 다운로드한 파일의 일치 여부를 확인할 때 사용합니다.              |

**DMG 설치 순서**

1. **macOS DMG 다운로드**를 눌러 파일을 받습니다.
2. 다운로드한 `.dmg`를 열고 **Cinema Bar.app**을 옆의 **Applications(응용 프로그램)**으로 드래그합니다.
3. 복사가 끝나면 디스크 이미지를 추출하고, **응용 프로그램 → Cinema Bar**를 실행합니다.
4. 상단 메뉴바의 **영사기 / CB** 아이콘을 누릅니다. 아이콘이 보이지 않으면 Dock에서 앱을 엽니다.
5. **감시 목록 → ＋ 추가**에서 극장·작품·날짜를 저장합니다.
6. 디스코드 알림도 받으려면 **설정 → Discord 연결**에서 자신의 웹훅을 연결합니다.

ZIP을 선택했다면 압축을 풀고 **Cinema Bar.app**을 응용 프로그램 폴더에 복사한 뒤 3번부터 진행하세요. 각 사용자에게 빈 감시 목록으로 시작하며, 배포 파일에는 제작자의 감시 설정이나 웹훅이 들어 있지 않습니다.

**첫 실행에서 macOS가 앱을 차단하는 경우**

현재 배포본은 로컬 임시 서명(ad-hoc)을 사용하며 **Apple Developer ID 서명·공증 전**입니다. 따라서 다운로드 후 첫 실행이 차단될 수 있습니다. 이 저장소에서 받은 파일임을 확인한 뒤 앱을 한 번 실행하고, **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**로 허용하세요. 자세한 절차는 [Apple의 앱 실행 안내](https://support.apple.com/ko-kr/102445)를 참고하세요.

공개된 macOS 설치 파일은 **Apple Silicon(M1 이상)**용입니다. Intel Mac과 Linux용 설치 파일은 이번 릴리스에 포함하지 않습니다.

**기존 사용자 업데이트**

실행 중인 Cinema Bar를 **앱 종료**로 끝낸 뒤 응용 프로그램 폴더의 앱만 교체하세요. 아래의 사용자 데이터 폴더는 그대로 두면 감시·설정·웹훅·알림 기록을 이어서 사용할 수 있습니다.

```text
~/Library/Application Support/Cinema Bar/
```

제거하려면 **설정 → 로그인 후 자동 시작**을 끄고 **앱 종료**를 누른 뒤 응용 프로그램 폴더의 Cinema Bar를 휴지통으로 옮기세요. 위 사용자 데이터 폴더는 유지됩니다.

### Windows 앱으로 사용하기

| 다운로드                                                                                                                                 | 대상과 용도                                                 |
| ---------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **[Windows Setup 다운로드](https://github.com/BS-Stack-Lab/cinema-bar/releases/download/v0.2.0/Cinema-Bar-0.2.0-Windows-x64-Setup.exe)** | Windows 10/11 · x64 · 권장. 현재 사용자에게 설치합니다.     |
| [Windows ZIP 다운로드](https://github.com/BS-Stack-Lab/cinema-bar/releases/download/v0.2.0/Cinema-Bar-0.2.0-Windows-x64.zip)             | Windows 10/11 · x64 · 압축을 풀어 직접 실행하는 대안입니다. |

1. **Windows Setup 다운로드**로 받은 파일을 실행합니다. 관리자 권한 없이 `%LOCALAPPDATA%\Programs\Cinema Bar`에 설치합니다.
2. 바탕 화면 바로가기는 설치 중 선택할 수 있습니다. 설치를 마친 뒤 **시작 메뉴 → Cinema Bar**로 실행합니다.
3. 작업 표시줄의 알림 영역에서 영사기 아이콘을 누릅니다. 숨겨진 아이콘 목록도 확인하세요. **감시 목록 → ＋ 추가**에서 첫 감시를 저장하고, 필요하면 자신의 Discord 웹훅을 연결합니다.

ZIP을 선택했다면 쓰기 가능한 폴더에 전체 압축을 풀고 **Cinema Bar.exe**를 실행하세요. EXE와 함께 있는 `resources` 등 다른 파일도 필요합니다. 새 사용자는 빈 감시 목록과 연결되지 않은 웹훅으로 시작합니다. 위의 공통 [SHA256 체크섬](https://github.com/BS-Stack-Lab/cinema-bar/releases/download/v0.2.0/SHA256SUMS.txt)으로 다운로드한 파일을 확인할 수 있습니다.

Windows 설치 파일과 앱은 **코드 서명되지 않았습니다**. Windows가 경고를 표시할 수 있으므로 다운로드 출처와 체크섬을 확인하세요.

**업데이트와 제거**

실행 중인 앱을 **앱 종료**로 끝낸 뒤 새 Setup 파일을 실행해 같은 위치에 설치하세요. ZIP은 앱 종료 후 새 압축의 전체 파일로 교체합니다. 앱 내 업데이트 확인과 검증 다운로드를 사용할 수 있으며, 설치 완료는 직접 진행합니다. ZIP에서 Setup으로 업데이트하면 설치본이 생깁니다. 제거할 때는 먼저 앱의 **설정 → 로그인 후 자동 시작**을 끄고 **앱 종료**를 누른 뒤 **Windows 설정 → 앱 → 설치된 앱(또는 앱 및 기능) → Cinema Bar → 제거**를 사용하세요. ZIP은 종료 후 압축을 풀었던 폴더를 삭제합니다.

설치·재설치·제거는 아래 사용자 데이터를 유지합니다. 감시·설정·암호화된 웹훅·기록을 계속 사용하려면 이 폴더를 보관하세요. 재설치할 때 지울 필요가 없습니다.

```text
%APPDATA%\Cinema Bar\
```

**배포 검증 환경**

Windows 빌드와 설치·정상 첫 실행·114개 desktop smoke 검사·동일 버전 재설치·제거 검증은 GitHub의 **Windows Server 2025 x64 runner**에서 수행합니다. Windows 10/11 실제 기기의 GUI, SmartScreen 평판, 재부팅 후 자동 시작, 개인 OS 암호화 저장소와 실제 영화관 조회·Discord 전송은 이 자동 검사 범위에 포함하지 않습니다. macOS는 Apple Silicon에서 별도 네이티브 검증하며, macOS 전용 Dock 검사 7개를 더해 총 121개를 확인합니다.

### 앱에서 업데이트하기

**0.1.0 사용자는 위의 0.2.0 설치 파일을 한 번 직접 받아 설치하세요.** 0.2.0부터 **설정 → 앱 업데이트**에서 실행 중인 버전과 새 정식 릴리스를 확인할 수 있습니다. 최신 릴리스가 현재 버전과 같으면 최신 상태로 표시합니다.

1. **업데이트 확인**을 누르고 새 버전이 있으면 **업데이트 다운로드**를 선택합니다. 진행률을 확인하거나 **다운로드 취소**로 중단할 수 있습니다.
2. 다운로드와 SHA256 검증이 끝나면 **설치 파일 열기**를 누릅니다. 열기에 실패하면 감시는 계속되며 같은 파일의 열기를 다시 시도할 수 있습니다.
3. **Cinema Bar를 앱 종료로 끝낸 뒤 설치를 완료하세요.** macOS는 DMG에서 앱을 응용 프로그램으로 드래그해 교체합니다. Windows는 기존 앱과 같은 위치에 Setup으로 설치합니다. 감시 조건·설정·웹훅·알림 기록은 유지됩니다.

앱은 파일을 자동으로 받거나 설치하거나 종료하지 않습니다. 패키지로 실행한 macOS Apple Silicon과 Windows x64에서 시작 10초 후, 이후 6시간 간격으로 확인합니다. 수동 확인은 최소 60초 간격, 최근 한 시간 최대 5회이며 GitHub의 요청 대기도 따릅니다. 마지막 시도와 대기는 앱을 다시 실행해도 유지합니다. 개발 실행과 다른 CPU·운영체제는 앱 내 업데이트를 지원하지 않습니다.

확인 요청 전에 별도 `update-check.json`에 최대 24시간의 보수 대기를 먼저 저장합니다. 통신 중 종료·응답 불명확·결과 저장 실패 시 표시된 시각까지 기다린 뒤 다시 확인하세요. 확인 기록의 형식이나 권한에 문제가 있으면 업데이트 확인만 중지합니다. 저장 폴더 권한을 복구한 뒤 다시 시도할 수 있으며, 손상된 일반 기록 파일의 복구도 최대 24시간 대기 후 확인합니다. 저장 처리가 2초 이상 지연되면 앱 재실행을 안내합니다. 개인 설정 파일을 지울 필요는 없습니다.

설치 파일은 **다운로드 폴더의 `Cinema-Bar-update-`로 시작하는 별도 폴더**에 저장됩니다. 취소·오류 시 자기 부분 파일을 정리하며, 사용자가 앱을 종료하면 정리 대기는 최대 5초입니다. 파일 작업 거부·지연·강제 종료 시 `.part`가 남을 수 있습니다. 준비되었거나 열린 설치 파일은 보관하므로 설치 후 불필요한 해당 폴더는 직접 삭제할 수 있습니다.

공개 저장소의 정확한 설치 파일 이름, HTTPS 허용 주소, API 크기·SHA256과 실제 파일의 일치를 확인합니다. SHA256 검사는 OS 코드 서명·발행자 인증을 대신하지 않습니다. GitHub 다운로드 주소 정책이 바뀌거나 digest가 없으면 설치를 차단하므로 공개 릴리스와 안내를 확인하세요. 기존 macOS 임시 서명·Windows 미서명 안내는 그대로 적용됩니다.

### 소스에서 직접 실행하기

Node.js **22.12 이상**과 npm을 준비한 뒤 저장소 루트에서 실행합니다.

```sh
npm ci
npm run dev
```

설치형 앱을 직접 빌드하려면 다음 명령을 사용합니다.

```sh
npm run build
```

현재 실행 중인 OS와 CPU에 맞는 패키지가 `release/`에 생성됩니다. macOS Apple Silicon의 결과는 다음 위치입니다.

```text
release/Cinema Bar-darwin-arm64/Cinema Bar.app
```

Windows x64에서는 `release/Cinema Bar-win32-x64/Cinema Bar.exe`가 생성됩니다. Windows 설치 파일을 만들려면 Inno Setup 6으로 `scripts/windowsInstaller.iss`를 컴파일하며, 저장소의 Windows workflow가 빌드부터 설치 검증까지 실행합니다. 로그인 후 자동 시작은 패키지로 설치한 앱에서 설정합니다.

## 첫 감시 등록하기

1. **감시 목록 → ＋ 추가**를 누릅니다.
2. **영화관 → 지역 → 극장**을 차례로 선택합니다. 극장 ID를 직접 찾을 필요가 없습니다.
3. **작품 검색**에 제목 일부를 입력하고 **검색 결과에서 작품을 선택**합니다.
4. **상영일**과 **상영 포맷**을 고릅니다.
5. 원하면 **가장 빠른 회차만 알림** 버튼을 켭니다.
6. **저장 후 감시 켜기**를 확인하고 **감시 저장**을 누릅니다.

작품은 영화관의 공식 예매 목록에서 검색합니다. 아직 목록에 없는 작품은 나중에 **목록 새로고침**으로 다시 확인하세요. 각 감시는 **지정한 날짜**를 대상으로 하며, 매주 같은 요일을 반복하는 예약은 현재 제공하지 않습니다.

### 알림은 언제, 몇 번 오나요?

| 저장한 조건                              | 알림 동작                                                                                                              |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **모든 포맷**                            | 같은 작품·극장·날짜의 예매가 열리면 앱과 디스코드에 각각 한 번 알립니다. 가장 빠른 시간과 실제 포맷을 함께 표시합니다. |
| **특정 포맷 + 가장 빠른 회차만 알림 켬** | 선택한 포맷에 맞는 가장 빠른 미래 회차 한 건을 날짜별 한 번 알립니다.                                                  |
| **특정 포맷 + 가장 빠른 회차만 알림 끔** | 조건에 맞는 예매 가능 회차를 회차별로 알립니다.                                                                        |

- 이미 예매가 열려 있어도 **저장 후 첫 성공 조회**에서 알립니다.
- **모든 포맷**은 여러 포맷과 시간대가 한꺼번에 열려도 알림 한 건으로 안내합니다.
- 날짜별 단일 알림을 이미 받았다면 이후 회차 추가나 더 빠른 회차 발견으로 반복 알리지 않습니다. 선택 버튼을 껐다 다시 켜도 같은 날짜의 완료 기록을 유지합니다.
- 날짜·작품·극장 등 감시 범위를 바꾸면 새로운 조건으로 확인합니다.
- 앱과 디스코드는 목적지별로 기록합니다. 앱 알림만 먼저 사용하다 디스코드를 연결하면, 다음 성공 조회에서 디스코드에 아직 알리지 않은 조건을 안내할 수 있습니다.

알림의 표시 형식은 다음과 같습니다.

```text
🎬 저장한 작품
CGV · 선택한 극장
2026-10-24 18:10 · 2D · 3관
가장 빠른 예매 가능 회차를 찾았어요
```

## 디스코드 연결하기

**자신의 서버와 채널에서 웹훅을 직접 만든 뒤 앱에 연결합니다.** 별도 봇 계정을 발급하거나 다른 사용자의 연결 정보를 공유할 필요가 없습니다.

1. 알림을 받을 디스코드 서버의 텍스트 채널을 선택합니다.
2. **채널 설정 → 연동 → 웹후크**에서 새 웹훅을 만듭니다. 웹훅 관리 권한이 필요합니다.
3. 알림을 받을 채널과 표시 이름을 확인하고 **웹후크 URL 복사**를 누릅니다.
4. Cinema Bar의 **설정 → Discord 연결 → 개인 웹훅 주소**에 붙여 넣습니다.
5. **안전하게 연결**을 누릅니다. 기존 연결을 바꿀 때는 **연결 교체**를 사용합니다.

연결 없이도 앱 팝업은 사용할 수 있습니다. 웹훅 주소는 저장 후 화면에 다시 표시하지 않으며, 디스코드 연결을 제거하려면 **연결 삭제**를 누릅니다.

웹훅 주소는 메시지를 보낼 수 있는 비밀 주소입니다. 저장소·공개 스크린샷·공유 문서에 넣지 마세요.

## 메뉴바와 알림 사용하기

| 화면          | 할 수 있는 일                                                                      |
| ------------- | ---------------------------------------------------------------------------------- |
| **대시보드**  | 활성 감시 수, 전송 대기, 최근 조회 상태를 확인합니다.                              |
| **감시 목록** | 포스터와 가장 빠른 회차를 보고, 감시를 추가·수정하거나 개별로 켜고 끕니다.         |
| **알림 기록** | 최근 100개의 앱 알림 표시 요청과 디스코드 전송 결과를 확인합니다.                  |
| **설정**      | 앱 알림, 개인 웹훅, 조회 간격, 로그인 후 자동 시작, 자동 잠자기 방지를 설정합니다. |

- 상단 **Cinema Bar 헤더를 드래그**하면 창을 이동할 수 있습니다.
- 창을 닫거나 숨겨도 감시는 이어집니다. **앱 종료**를 누르면 감시도 종료됩니다.
- 앱 팝업은 화면 우측 상단에 표시되고 약 8초 뒤 닫힙니다. macOS 알림센터에는 남지 않습니다.
- 메뉴바 아이콘이 보이지 않을 때는 **Dock에서 Cinema Bar를 열어** 상태를 확인할 수 있습니다.

조회 간격은 새 설치 기준 **120초**, 설정 가능한 범위는 **60~3600초**입니다. 네트워크나 영화관 측의 요청 제한이 있으면 다음 조회가 늦어질 수 있습니다.

## 화면이 꺼지거나 재부팅하면 어떻게 되나요?

**설정 → 감시 중 자동 잠자기 방지**를 켜면 활성 감시가 작동하는 동안 자동 시스템 잠자기를 막아, 화면이 꺼져도 감시를 이어갈 수 있습니다. 이 설정은 기본적으로 꺼져 있으며 배터리 사용량이 늘어날 수 있습니다.

| 기기 상태                              | 동작                                                                     |
| -------------------------------------- | ------------------------------------------------------------------------ |
| 화면만 꺼짐 + 자동 잠자기 방지 작동 중 | 감시를 계속합니다.                                                       |
| 수동 잠자기·노트북 덮개 닫힘           | 잠자기 동안 감시가 멈추고, 깨어나면 다시 조회합니다.                     |
| 네트워크 연결 끊김                     | 감시가 대기하다 연결 복구 후 다시 확인합니다.                            |
| 전원 꺼짐                              | 감시가 멈춥니다. 로그인 후 자동 시작을 켰다면 다음 로그인 뒤 재개합니다. |
| 전체 일시 정지·앱 종료                 | 사용자가 다시 실행할 때까지 감시를 멈춥니다.                             |

패키지 첫 실행은 **로그인 후 자동 시작**을 켭니다. 설정에서 끄면 그 선택을 유지합니다. 로그인 전 부팅 단계에서 실행하는 시스템 서비스는 아닙니다.

## 자주 묻는 질문

### 비용이 드나요?

감시와 알림 전송은 설치한 컴퓨터에서 실행하므로 중앙 감시 서버 운영비가 필요하지 않습니다. CPU·메모리·네트워크·전력은 각 사용자의 기기에서 사용합니다.

### 예매나 결제도 해주나요?

Cinema Bar는 예매 가능한 회차를 확인해 알림을 보냅니다. 실제 좌석 선택·예매·결제는 공식 영화관에서 진행합니다.

### 알림이 늦거나 같은 알림이 다시 올 수도 있나요?

주기 조회 방식이므로 오픈 순간과 알림 사이에 차이가 생길 수 있습니다. 영화관 응답 지연이나 요청 제한은 오류로 표시합니다. 조건에 맞는 회차가 없다는 뜻으로 바꿔 처리하지 않습니다.

앱은 목적지별 중복 기록을 사용합니다. 다만 디스코드 전송 응답이 불명확한 상태에서 재시도하면 같은 메시지가 다시 도착할 수 있습니다. 앱도 표시 기록 저장과 실제 팝업 표시 사이에 종료되면 팝업을 놓칠 수 있습니다.

### 내 설정과 웹훅은 어디에 저장되나요?

감시 조건·설정·알림 기록은 OS 사용자별 앱 데이터에 저장합니다. macOS 설치 앱의 경로는 다음과 같습니다.

```text
~/Library/Application Support/Cinema Bar/
```

웹훅은 Electron `safeStorage`로 암호화합니다. OS 암호화 저장소에 연결할 수 없으면 디스코드 연결 저장·전송이 제한되며, 앱 팝업은 별도로 사용할 수 있습니다.
